# หมูพริ้ว POS · JLK Tower (เวอร์ชัน dummy)

แอปจดบิลบนมือถือ Android ก่อนกดเครื่องคิดเงินของศูนย์อาหาร ใช้ออฟไลน์ได้ ส่งเข้า Supabase ทุกชั่วโมง แล้วออก CSV ให้โปรแกรม import ชีทเดิม

## ติดตั้ง 4 ขั้น

1. **Supabase**: เปิด SQL Editor วางไฟล์ `supabase.sql` แล้วกด Run (รันซ้ำได้ ไม่ทับข้อมูล)
   - รหัสลับเริ่มต้นของสาขา `jlk` คือ `CHANGE-ME-jlk` **ให้เปลี่ยนก่อนใช้จริง** (คำสั่งอยู่ท้ายไฟล์)
2. **โฮสต์ไฟล์** โฟลเดอร์นี้ (static ล้วน ต้องเป็น https) เช่น Cloudflare Pages หรือ GitHub Pages
3. **เปิดลิงก์ใน Chrome บนมือถือ Android** → เมนู ⋮ → "ติดตั้งแอป" (ครั้งแรกต้องมีเน็ต)
   - ตั้งค่าแบตเตอรี่ของ Chrome ให้ "ไม่จำกัด" เพื่อให้ซิงก์เบื้องหลังทำงานได้
4. ในแอปไปที่ **ตั้งค่า** → ใส่ Project URL, anon/publishable key (ห้ามใช้ service role) และรหัสลับ → บันทึก

## วิธีใช้ที่ร้าน

1. แตะเมนูบนมือถือ (แตะซ้ำ = เพิ่มจำนวน) เลขดำที่มุมปุ่มคือเลขที่ต้องกดบนเครื่อง
2. แอปแสดงลำดับปุ่มที่ต้องกดบนเครื่อง เช่น `1 E ×2 › 2 E › D 3` (E = ENTER, D = ไปหน้าชำระเงิน, เลขท้าย = ช่องทางชำระ)
3. กดเครื่องตามนั้น แล้วกด **กดเครื่องแล้ว · บันทึกบิล**
4. กดผิด/ยกเลิก: ปุ่ม "ยกเลิกบิลนี้" ในแอป พร้อมกด **C 2 ครั้ง** บนเครื่อง (บิลที่ยกเลิกไม่นับในยอดและ CSV)

## ส่งออกไปชีท

- **แท็บ สรุป/ส่งออก** → เลือกวัน → "ดาวน์โหลด CSV" หรือ "แชร์ไฟล์ CSV"
- หรือดึงจาก view `pos_daily_item_summary` ใน Supabase (คอลัมน์เดียวกัน)
- รูปแบบ: `date,branch,item_code,item_name,price,qty,amount` (UTF-8 ไม่มี BOM, วันที่ `YYYY-MM-DD`, ไม่มีแถวคำอธิบาย)
- ไฟล์หนึ่งไฟล์ = ยอดทั้งวัน ถ้านำเข้าหลายครั้งในวันเดียว ให้ตรวจก่อนว่าโปรแกรม import เขียนทับหรือต่อท้าย (ถ้าต่อท้าย จะนับซ้ำ)

## สิ่งที่ยังเป็นค่าสมมติ (แก้ในแอป ตั้งค่า → เมนู ไม่ต้องแก้โค้ด)

- เลขที่กดบนเครื่องของแต่ละเมนู (ตอนนี้ 1–14 สมมติ) และรหัสระบบ (อิง Item Master ของ แฟชั่น B)
- ราคา และชื่อสาขา (`JLK Tower`)
- วิธีใส่จำนวน: ตอนนี้ถือว่าสั่ง n จานคือกด `รหัส E` ซ้ำ n ครั้ง
- ช่องทางชำระใช้หน้า 1 ของเครื่อง (1–8) หน้า 2 ถ้ามีต้องเพิ่มใน `config.js`

รูปแบบเมนูในช่องแก้ไข: `เลขกดเครื่อง,รหัสระบบ,ชื่อ,ราคา,กลุ่ม` หนึ่งบรรทัดต่อเมนู

## การส่งข้อมูล

- ส่งทุก 1 ชั่วโมงตอนเปิดแอป ถ้าส่งไม่สำเร็จลองใหม่ใน 5 นาที และบน Android จะส่งเองเมื่อสัญญาณกลับมา
- มุมบนขวาเป็นแดงถ้ามีบิลค้างเกิน 1 ชั่วโมง มีปุ่ม "ส่งตอนนี้" ในแท็บ สรุป/ส่งออก
- ส่งซ้ำได้ปลอดภัย (ฝั่งเซิร์ฟเวอร์ตัดบิลซ้ำด้วยรหัสบิล) ไฟล์สำรอง JSON ในแท็บเดียวกันใช้ตอนเปลี่ยนเครื่อง

## อัปเดตแอป

แอปเก็บตัวเองไว้ในเครื่อง หลังอัปโหลดเวอร์ชันใหม่ ให้เปิดแอปแล้วปิด-เปิดอีกครั้งจึงจะได้เวอร์ชันใหม่ (ถ้าแก้ไฟล์แล้วอยากบังคับ ให้เปลี่ยนเลขใน `CACHE` ที่หัวไฟล์ `sw.js`)

## ไฟล์
